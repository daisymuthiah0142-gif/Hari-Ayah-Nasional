# Hari Ayah Nasional 🌼

Kartu digital interaktif untuk Ayah, dibuat dengan HTML, CSS, dan JavaScript.

## Halaman

1. **Masukkan Nama** — input nama ayah untuk mulai
2. **Video** — video bunga dengan ucapan selamat
3. **Memori** — dua foto kenangan bersama ayah
4. **Ucapan** — pesan dari Tia dan Mora
5. **Penutup** — foto polaroid dan ucapan terima kasih

## File

- `html.html` — struktur halaman
- `css.css` — tampilan dan animasi
- `js.js` — logika interaktif
- `media/` — video, foto, font, dan audio
